# A two-minute Proto-Mind walkthrough

This is a fictional client project, not a saved or pre-generated AI result.
Use your own account. Select GPT-6 Astra if your account provides it. Text chat
needs no API key; the optional voice steps require your own separately billed
OpenAI API connection. A real answer must be generated during the recording.

## Prepare once

1. Copy this folder somewhere writable and open it as a project in Proto-Mind.
2. In a terminal in this folder, run `python3 serve.py`. If Python is not installed,
   use the bundled runtime after installing the portable app:
   `"/Applications/Proto-Mind.app/Contents/Resources/runtime/python/bin/python3" serve.py`.
   The server exposes only the sample brief to this Mac. Ctrl+C stops it.
3. Open the printed address in a PM browser panel.
4. Open **Project memory → New note**. Save this preference:
   **“For Northstar proposals: use EUR, keep the proposal under 250 words, and end with three client questions.”**
   Close the memory screen; leave automatic project recall on.
5. Choose English in Settings → Appearance if needed, then restart before recording.
   Enable floating mode, place the cube and one companion window, and close unrelated apps/pages.

## Show a real workflow

- **0:00–0:15:** Hover over the cube, move away, then click to keep the workspace open.
- **0:15–0:40:** Show the brief beside the chat. Click **Use in a task**. Select the
  project conversation and enter **“Prepare a proposal for Northstar from this brief.”**
  Add it to the draft and send. The text and source appear in the user message;
  expand “Browser reference” briefly to show what was actually sent.
- **While it works:** Send **“Also separate assumptions from included work.”**
  If the first response has already finished, show this as a follow-up rather than
  claiming it interrupted active work.
- **Optional voice alternative:** Say **“Use the Northstar browser page to prepare
  a proposal in the current task.”** Then give the same clarification by voice.
  Voice delegates to the selected task's model; it is a separate API service.
- **0:40–1:30:** When the answer completes, click **Open response beside chat**.
  Read the actual result. Show the scope, estimate, assumptions and questions.
  If it missed a requirement, correct it; do not replace it with a canned answer.
- **1:30–2:00:** Create another conversation in the same project. Ask
  **“What should a Northstar proposal include, and how should it be formatted?”**
  Show whether the saved project preference was recalled. Open Project memory
  to demonstrate that the note can be edited or removed.

Long model waits may be cut from the video; label cuts. Keep the visible model
name accurate. This walkthrough demonstrates a workflow, not independent
verification of a model's output or proof that every task will succeed.

## Проверка перед записью

Материал вымышленный. Добавьте заметку вручную, выберите Astra и получите настоящий
ответ. Для первой попытки достаточно текста; голос можно показать после подключения
своего API. Не выдавайте тестовый режим или заранее написанный ответ за работу модели.

Сценарий: кубик → бриф справа → «Передать в задачу» → уточнение → ответ рядом → новый
диалог в той же папке с памятью проекта. После показа остановите сервер через Ctrl+C.
