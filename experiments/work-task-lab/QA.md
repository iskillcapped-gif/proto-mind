# Фактическая проверка · 2026-09-07

## Среда

Ubuntu Linux x86_64; Node 24.19.0; npm 11.9.0; Vinext/Vite/React; облачный Chrome. Интерфейс открыт по HTTP через supervised agent preview, а не как изображение или статический макет.

## Проверено действиями в работающем браузере

- Desktop: пустое добавление → ошибка; добавление задачи → строка, сброс поля, фокус и обновлённые счётчики.
- Редактирование: пустое название отклонено; новое название сохранено; «Отмена» оставляет прежнее название.
- Завершение и возврат в работу; состояние checkbox и счётчики изменяются.
- «Все», «В работе», «Готово», включая пустые отфильтрованные состояния.
- Mobile: тот же `/` во вложенном browsing context с `window.innerWidth = 390`; высота iframe 844 CSS px. `documentElement.clientWidth = scrollWidth = 375` (15 px занимает полоса прокрутки desktop Chrome). Горизонтального переполнения нет.
- Mobile: добавление, редактирование длинного названия, завершение, фильтрация, добавление через Enter из «Готово» с переходом в «Все», отмена редактирования через Escape.
- Визуально просмотрены скриншоты desktop и mobile; длинное название переносится, основные элементы доступны.
- В выборке console error с фильтром адреса приложения ошибок не найдено. В браузере присутствовали посторонние ошибки служебного расширения; это не «полностью чистая консоль».

## Найденные проблемы и исправления

1. **Реальная UI-ошибка:** `crypto.randomUUID` отсутствует на HTTP-origin preview; добавление не работало. Заменено на последовательные идентификаторы внутри экземпляра списка (данные только в памяти). Добавлен тест на 1000 уникальных ID без зависимости от secure-context API; добавление повторно проверено в браузере.
2. **Точность мобильного стенда:** рамка отнимала 2 px от viewport. Заменена на outline; итоговая ширина подтверждена через DOM: `window.innerWidth = 390`.
3. **Типы стартера:** начальный `tsc` не находил типы Worker/D1. Добавлены зафиксированный `@cloudflare/workers-types` и корректное дополнение `Cloudflare.Env`; повторный `npx tsc --noEmit` завершился с кодом 0.

## Автоматические проверки

- 10 тестов логики задач: добавление, trimming, пустые значения, граница 160 символов, повторные ID, редактирование, неизменность исходных данных, завершение/возврат, фильтрация, HTML-подобный текст как данные, генератор ID.
- 2 production/SSR теста: реальный `Worker.fetch`, HTML/метаданные, русская форма, закрытый production-маршрут QA.
- 4 проверки компонентов/стилей стартера.
- Production build успешно завершён.
- `npx tsc --noEmit`: exit 0.

Browser QA проводилась отдельными последовательными вызовами браузерных инструментов с DOM-проверками, а не включена в `npm test`. Воспроизводимый ручной сценарий приведён в README.

## Границы проверки

Не проверялись физический телефон, Safari/iOS, touch-жесты, экранная клавиатура, screen reader, нагрузка или много пользователей. Проверка ширины через iframe не является полной эмуляцией мобильного устройства. После публикации живой production URL облачным браузером не открывался: UI QA относится к работающему preview, production-обработчик отдельно проверен тестами. Постоянное хранение/синхронизация задач не реализованы; перезагрузка очищает список. Полный набор тестов основного Proto-Mind не запускался: его исходники не менялись.
