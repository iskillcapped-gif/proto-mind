# VIREN Task Lab

Небольшое тестовое приложение: добавление, редактирование, завершение/возврат в работу и фильтры «Все / В работе / Готово». Русский интерфейс, управление клавиатурой, адаптивная вёрстка.

**Данные живут только в памяти вкладки до перезагрузки страницы.** Базы данных, учётных записей и синхронизации задач между устройствами нет. Это эксперимент для проверки полного цикла облачной разработки.

## Воспроизводимый запуск

Проверено в Linux с Node.js 24.19.0 и npm 11.9.0. Требуется Node.js 24.x. Для `npm run build` используется GNU `timeout` (на macOS: `brew install coreutils`; либо используйте напрямую `npx vinext build`).

```bash
git clone --branch experiment/work-task-lab --single-branch https://github.com/iskillcapped-gif/proto-mind.git
cd proto-mind/experiments/work-task-lab
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
```

Откройте http://localhost:4173. Для доступа с другого устройства в вашей сети используйте `--host 0.0.0.0` и адрес вашего компьютера; сетевые настройки остаются под вашим контролем.

```bash
# Быстрые тесты логики без сборки
node --test tests/tasks.test.mjs
# Полная сборка и автоматические тесты, включая реальный Worker.fetch
npm test
# Проверка TypeScript
npx tsc --noEmit
# Production: сначала сборка, затем сервер
npm run build
npm start -- --port 4173
```

Зависимости зафиксированы в package-lock.json; секреты и API-ключи не нужны. `.openai/hosting.json` описывает размещение этого экземпляра в Sites, но не содержит учётных данных и не нужен для доступа к чужим аккаунтам.

## Проверка интерфейса

Откройте `/qa/mobile` в режиме разработки: это тот же работающий `/` внутри iframe с viewport 390 × 844 CSS px. Страница QA недоступна в production. Это проверка ширины, не эмуляция телефона, touch, Safari или мобильной клавиатуры.

1. Нажмите «Добавить» с пустым полем: должна появиться ошибка.
2. Добавьте две задачи; одну через Enter. Поле очищается, счётчики растут.
3. Отредактируйте первую задачу, затем попробуйте пустое название: сохранение блокируется.
4. Измените название и сохраните; отдельную попытку отмените кнопкой «Отмена» или Escape.
5. Завершите первую задачу. Проверьте все три фильтра и счётчики.
6. Верните завершённую задачу в работу; она должна исчезнуть из «Готово».
7. Добавьте задачу, находясь в «Готово»: список переключается на «Все», новая задача видна.
8. На `/qa/mobile` повторите основные действия и проверьте длинное название без горизонтального скролла.

Подробный фактический отчёт — `QA.md`.

## Структура

- `app/page.tsx` — работающий интерфейс;
- `lib/tasks.ts` — чистые операции над задачами и генерация ID;
- `app/globals.css` — desktop/mobile оформление;
- `app/qa/mobile/page.tsx` — development-only мобильный стенд;
- `tests/tasks.test.mjs` — 10 тестов логики;
- `tests/rendered-html.test.mjs`, `tests/ui-components.test.mjs` — проверки сборки и компонентов стартера;
- `worker/`, `build/`, `vite.config.ts` — Vinext / Cloudflare инфраструктура.

Эксперимент изолирован в отдельной папке и ветке. Основные файлы Proto-Mind не изменяются.
